🏥 Patient Medical History RAG

Retrieve and analyze patient records using AI
⚡ Powered by Groq · Llama 3 70B · PubMedBERT · Qdrant

This system retrieves patient medical history from the MIMIC-IV dataset (MEDS format) using PubMedBERT for semantic search via Qdrant, and generates structured answers using Llama 3 70B via Groq cloud inference (~500 tokens/sec).
